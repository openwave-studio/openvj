## MODIFIED Requirements

### Requirement: Resolume-style where chosen
Parameters SHALL stay Resolume-style horizontal bars (no knobs), and the clip grid SHALL keep spaced cells. Other Resolume-style elements need the maintainer's approval, shown as a mockup first. The one exception is the Synthesis layout, whose macros and parameters SHALL be standardized knobs.

#### Scenario: Effect parameter
- **WHEN** an effect card shows a parameter
- **THEN** it is a horizontal value bar

#### Scenario: Synthesis macro
- **WHEN** the Synthesis layout shows a macro or a section parameter
- **THEN** it is a knob in the shared Synthesis style
